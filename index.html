FAQ

What is Treasure Client?

Treasure Client is a custom EaglerCraft client — a browser-based build of Minecraft 1.12.2 with extra mods and a built-in mod menu.

Is it free?

Yes, completely free. There are no paywalls and no account is required.

Which version is it based on?

The current release (1.1) is based on EaglerCraft 1.12.2.
